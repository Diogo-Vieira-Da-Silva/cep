 📝 Projeto de Consulta de CEP com HTML, CSS e JavaScript

Este é um projeto simples desenvolvido com HTML, CSS e JavaScript puro, com foco em:

Busca de informações de endereço a partir de um CEP digitado;

Integração com API pública de CEP (ViaCEP);

Exibição dinâmica dos dados retornados (rua, bairro, cidade, estado);

Feedback visual e mensagens de erro para CEPs inválidos ou não encontrados;

Design limpo, responsivo e de fácil compreensão.

📌 Funcionalidades

Campo de entrada para digitar o CEP;

Botão de pesquisa que aciona a busca na API;

Exibição automática das informações correspondentes;

Mensagem de aviso quando o CEP não é encontrado;

Layout centralizado com estilo moderno e sombras suaves.

🧠 Tecnologias utilizadas

HTML5 para a estrutura da página;

CSS3 para o design e responsividade;

JavaScript (Vanilla JS) para a integração com a API e manipulação do DOM;

Fetch API para obter os dados de endereço em tempo real.

🧪 Como testar

Clone ou baixe este repositório.

Abra o arquivo .html em qualquer navegador moderno.

Digite um CEP válido no campo de texto.

Clique em Buscar.

Veja as informações completas do endereço retornadas na tela.

💬 Reflexão sobre o projeto

Eu já havia desenvolvido um projeto semelhante anteriormente, o que me deixou confiante para iniciar esta versão. Apesar das semelhanças, fiz ajustes e adaptações específicas para este caso, incluindo novos links e informações. No começo, tive dúvidas sobre a complexidade e o número de funcionalidades que implementaria, mas o resultado final se mostrou equilibrado e funcional.

Foi uma experiência simples, porém bastante satisfatória e enriquecedora, que me permitiu reforçar conceitos e práticas em JavaScript, integração com APIs e manipulação de dados dinâmicos.
